# ログから原因を特定する

## 観測と解釈を分ける

人間ログは成功例、現行AIのログは比較対象。AI版が記録されていない過去ログの版を推定で断定しない。JSONLはイベント単位であり、一行を一ターンとみなさない。Entityのindexは再利用されるため、完全ID/世代と生成・消滅イベントを対応付ける。

実際のキーを先に調べる。`eval_matchup.py` の結果では次が入口になるが、未記録項目はゼロで補わない。

| データ | 調べる内容 |
|---|---|
| `metadata`, `results[].map/p1/p2/seed/grid_type` | 対戦条件・上限・評価対象の手番 |
| `strategic_history` | 座標、HP、拠点所有者、各前線の状態 |
| `production_plan_history` | 役割、工場、予測初撃・撃破・占領時刻 |
| `deployment_audit_history` | 購入Entityと配備任務の対応、敵優先順、現標的、初撃実績 |
| `plan_revision_history`, `plan_execution_history` | 計画がいつ、なぜ置換・中止されたか |
| `capital_route_history` | Squad目標と実行目標、経路・phaseの差 |
| `action_history`, 実行イベント | 最終命令、合法性、実際の位置・損害 |
| `metrics`, `thinking_times`, `action_counts` | 同じ時点の成果、思考時間、生産内訳 |

「西側で攻撃した」は観測。「東側に行く予定を上書きされた」は、計画と中間状態をつないで初めて確認できる原因。「両面に戦力を分ければ勝つ」は、まだ検証していない仮説。

## 最初の食い違いを記録する

対局全体を毎回読み直さず、結果に効く最初の数手を選ぶ。必要なら次の表を短く作り、未観測の境界だけ計測する。

| turn / player / Entity | 決定する処理・正本 | 入力 | 出力 | 次の処理で維持されたか |
|---|---|---|---|---|
| 生産手番 | 生産計画 | 盤面・合法候補 | 役割/敵/施設/予測時刻 | 配備台帳と照合 |
| 行動手番 | 配備・Squad・DAG | 同一Entityの任務 | 現標的/移動目標 | 戦術候補と照合 |
| 行動手番 | 戦術・実行 | 候補と制約 | コマンド/イベント | 予測時刻と照合 |

候補がないなら、合法性と候補除外を確認する。候補はあるが選ばれないなら、比較の単位と優先順を確認する。選んだ命令が変わるなら、別の正本・割り込み・再計算を確認する。実行しても成果が違うなら、予測モデルの移動、ZOC、反撃、占領、補給条件を調べる。

再現fixtureには問題に効く時点の地形、所属、HP、燃料、弾薬、行動済み状態、所持金、占領進捗を復元する。省略したものがあればテストの射程を明示する。必要なら同じ局面で修正前後の候補・命令・イベントを比較し、前線が崩れた後の局面だけで対策を決めない。

## 同時要件を測る

前線ごとの独立した最高値や別々の成功seedを足し合わせない。例えば「Aの拠点維持とBの獲得」なら、同じスナップショットで `owned(A) >= required_A AND owned(B) >= required_B` を計算する。

- 拠点集合、必要数、観測時点/期間、手番内の観測位置を明記する。
- 同時成立した対局数、初成立ターン、維持期間、確保後の喪失を区別する。一瞬の成立だけでは維持の証明にならない。
- 人間例の達成ターンとユーザーが要求した期限を区別する。診断用のT15などを勝手に合否条件へ格上げしない。
- 指定時点より前に終局した対局は「終局済み」とする。終局状態をその時点の観測として黙って持ち越さない。
- 同時要件以外でも、収入と損耗、生産数と到達時刻など、目的に必要な組み合わせを測る。兵種の偏りだけを悪化と判定しない。

## Map32で得た診断例（固定戦術ではない）

購入時の敵優先順が配備処理で距離順に変わり、さらにDAGが別の移動目標を与えていた。各層の単体評価が正しくても、正本が競合すれば予定した初撃は実現しない。上書き防止と任務終了後の復帰を一組の契約として検証する。

工場上の間接砲が射撃できるのに、退去可能という理由で射撃候補から消されていた。ここでは新しい加点より候補除外の修正が先になる。ただし、射撃継続が全体として最適とは限らない。弾薬補給、移動すると失う射撃手番、現在と次手番の発注ごとの必要工場・資金・出撃経路を確認する。「空き工場が一つある」で生産能力が足りるとは判断しない。
