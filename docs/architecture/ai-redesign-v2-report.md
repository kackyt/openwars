## 思考時間（map_6 seed1、V200先攻・V4後攻、単一スレッド `RAYON_NUM_THREADS=1`）

同じ対局（両者とも54ターンでV4勝利、行動列一致）での V4 の判断時間。

| | base | HEAD |
|---|---|---|
| 合計 | 210s | 87s |

| 最悪の1step | 17.3s（T48 生産） | 5.3s（T48 生産） |

速くした変更（すべてR、判断不変）:

- 生産計画の交戦シミュレーションを、親候補の途中状態から再開する（`CombatRun`）。
- 施設×兵種ごとの交戦条件表を1回だけ作る（`EngagementTemplate`）。
- 標的選択を静的な優先順で並べ、確定した時点で打ち切る。
- 占領出発の同期で地形連結の索引を呼出元から渡す。

残る最大の負荷は生産計画の交戦シミュレーション（`plan_force_package`、サンプルの約4割）。
5秒の停止はまだ長い。これ以上は探索幅を変える（=判断が変わる）必要があり、強さとの交換に
なるため、計画どおり相談事項とする。

## 構造（段階6のやり直し）

前回は29引数の関数を切り出しただけだった。今回は1回の行動選択を
「盤面の事実 → unitの事実 → 移動先候補 → 評価 → 選択」に分け、責務ごとの型にした。

| ファイル | 責務 |
|---|---|
| `tactics/board.rs` | 全unitが共有する盤面の事実（`TacticalBoard`、Squad任務 `SquadRoles`）。読み取り専用 |
| `tactics/unit.rs` | 版によらないunitの状態（HP・弾薬・戦闘不能・脅威近接） |
| `tactics/approach.rs` | 目標への接近の測り方と、手番内で共有する距離cache |
| `tactics/scoring.rs` | 版によらない採点項目（地形・V3位置取り・接近・攻撃・待機回復・合流）と候補比較 |
| `tactics/v2.rs` | V2/V3と通常V4の行動選択（版固有部分だけ） |
| `tactics/small_map.rs` | 小規模V4の契約だけ: 自軍生産口の閉塞、敵生産口の占位、DAG前進、占領契約、間接部隊の追随・定位置射撃 |
| `runtime/turn.rs` | V2〜V4の手番進行1本（通常/小規模の差は行動選択器の差し替えだけ） |

削除したもの: 小規模経路の手番ループ全文コピー、`decide_ai_action_v2_for_entities` の1540行の本文、

## 「V200に後攻で勝つ」について

- map_6 は base・HEAD とも後攻 6/6 勝ち（45〜56ターンで通常勝利）。前回ブランチより速く決着する。
- 負けが集中するのは小規模マップの後攻。先攻 V200 が中央の中立都市を先に取り、
  T6〜T10 の交戦で物件差か戦力差がつくと戻せない。seed（戦闘の乱数）だけで勝敗が入れ替わる局面が多く、
  6seedでは1〜3局の差は判別できない。
- map_18 は base でも両手番 0/3（すべて60ターン判定負け）。

後攻の小規模マップを改善する4つのSはいずれも明確な改善を示せず、採用していない。
「全マップで後攻でも勝つ」は未達。
