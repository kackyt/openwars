# ROADMAP.md - プロジェクトロードマップ

## 1. プロジェクト概要

### ビジョン
RustとECS(Entity Component System)を活用し、モジュール化され拡張性の高いターン制戦略シミュレーションゲームを構築する。

### ミッション
- ロジックとプレゼンテーションの完全分離を実証する
- AI技術を利用し、自律的なエージェントによるテストや対戦を可能にする

## 2. マイルストーン

### Phase 1: コアロジックとCUI基盤の実装

**目標**: ECSエンジンと `ratatui` を用いたターミナル画面でのゲーム進行

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M1.1: ECSエンジンの初期化 (`bevy_ecs`) | 完了 | ターン、ユニットコンポーネント |
| M1.2: コマンドとイベントの設計 | 完了 | UI・エンジン間の通信機構 |
| M1.3: CUIレンダラの構築 (`ratatui`) | 完了 | マップ描画、メニュー操作 |

### Phase 2: 戦闘ロジックとルールの拡充

**目標**: ターン制戦略ゲームとしての基本的な遊びが成立すること

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M2.1: ユニットの移動・攻撃・耐久値管理 | 完了 | 戦闘システム、AP管理 |
| M2.2: 拠点の占領・生産システム | 完了 | リソース・生産ロジック |
| M2.3: ルールエンジン（勝利条件・敗北条件） | 完了 | 勝敗判定システム |

### Phase 3: AIプレイヤーと自動テストの導入

**目標**: AIエージェントを利用した自律的なプレイ・テスト

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M3.1: コマンドラインからのバッチ実行モード | 完了 | UIなしでの高速シミュレーション |
| M3.2: 思考ルーチンの基礎実装 | 完了 | 敵AIの行動アルゴリズムの土台 |
| M3.3: 戦術AIの高度化 | 完了 | ユニット同士の連携、地形を利用した防衛、カミカゼ特攻の完全排除など |
| M3.4: v1,v2バージョンのAIを競わせた高度化 | 完了 | AI同士の自己対戦によるバランス調整とロジック改善 |
| M3.5: 特定マップでのAIベンチマークテスト拡充 | 完了 | MCPを活用した評価の自動化 |

### Phase 4: ゲーム基盤機能の完成（セーブ / ロード等）

**目標**: ECSアーキテクチャのシリアライズ機能を利用し、ゲームプレイの保存と再開を可能にする

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M4.1: ECSワールドステートのシリアライズ対応 | 予定 | 全エンティティ・コンポーネントの状態保存処理（serde等の活用） |
| M4.2: セーブデータの入出力機能とUI | 予定 | CUI上でセーブ・ロードを行うメニューと実際のファイルI/O機構 |
| M4.3: 任意局面からの再開（テスト応用） | 予定 | AIの特定シチュエーションでのテスト等に使える状態復元機能 |

### Phase 5: LLMを用いた動的司令官（LLM Commander）の導入

**目標**: 単なるロジックベースのAIではなく、LLM（大規模言語モデル）を組み込んだ自律的かつインタラクティブなAI司令官機能を実現する

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M5.1: LLMとのプロンプト・コンテキスト連携基盤 | 予定 | ゲーム状態（戦況・マップ）をLLMに解釈させる仕組み |
| M5.2: 自然言語による戦況報告・対話機能 | 予定 | プレイヤーの行動や戦局に合わせた動的なセリフ・テキスト生成 |
| M5.3: LLM主導による戦略的意思決定の実験 | 予定 | LLMが推論した戦術に基づくコマンド発行・行動選択 |

### Phase 6: ヘックス（六角形）マップオプションの実装

**目標**: 既存の四角形（スクエア）グリッドに加えて、マップタイプのオプションとしてヘックスグリッドを選択・遊べるように対応する

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M6.1: ヘックス座標計算・距離ロジックの実装 | 完了 | マップタイプに応じた座標変換、経路探索の切り替えロジック |
| M6.2: CUI描画のヘックス対応 | 完了 | ratatuiでの六角形風の描画調整 |

### Phase 7: GUIクライアント開発 (Tauri)

**目標**: TauriとWeb技術（React/Vue等）を用いたGUIアプリケーション版の作成

| 項目 | ステータス | 成果物 |
| --- | --- | --- |
| M7.1: Tauriバックエンド（`gui`）の初期化 | 予定 | Tauriプロジェクト構成 |
| M7.2: Webフロントエンドへのマップ描画 | 予定 | WebGL/Canvasによる描画 |
| M7.3: 正式リリース版ビルド | 予定 | 各OS向け実行ファイル |

## 3. 現在のステータス
現在は **Phase 3** のAI高度化（V3の実装）および **Phase 6** のヘックスマップ対応が完了しました。自動テスト環境・ベンチマークの拡充も進んでいます。今後は、セーブ・ロード機能の実装（Phase 4）や、GUIクライアントの開発（Phase 7）、LLMを用いた動的な司令官の実装（Phase 5）へと移行していく予定です。
