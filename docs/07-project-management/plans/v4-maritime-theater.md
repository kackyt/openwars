# V4 AI: 海上・航空戦域（艦船・島嶼間輸送・航空との連携）

## 背景

海と港のあるマップ（map_4, map_18, map_19, map_33, map_41, map_50）で、V4 は V200 に先攻・後攻の
両方で勝てなかった。対戦ログを調べると、原因は次の5つだった。

| 症状 | 原因 |
| --- | --- |
| 戦艦が一度も撃たない | 戦艦の主兵装は射程2〜6の間接射撃で、移動した手番には撃てない。汎用の戦術評価が毎手番移動させていた。 |
| 本拠島に地上部隊が溜まり、資金が20万〜60万積み上がる | 作戦生産が、陸路で前線へ届かない地上部隊（重戦車など）を買い続けた。港・空港も地上部隊に塞がれ、艦船・航空機を生産できなかった。 |
| 中立の島を占領しに行かない | 上陸部隊だけが居て拠点を持たない島を「脅威下の自軍島（防衛）」と分類し、完全な防衛編成を予約できずに監視へ落ちていた。 |
| 輸送部隊が積荷を降ろさない・往復しない | 輸送Squadが少数の輸送部隊しか扱えず、広い陸塊では陸塊全体の敵数で揚陸を見送っていた。 |
| 輸送部隊が増えると思考が止まる | 島嶼作戦の輸送割当が輸送役数の指数時間の全探索だった。 |

## 設計

`engine/src/ai/v4/maritime/` に海上・航空戦域の層を置き、V4 の手番進行（`runtime/turn.rs`）から呼ぶ。

| モジュール | 役割 |
| --- | --- |
| `theater` | 盤面から戦域の事実を求める。首都同士が海で隔てられているか、自軍の港から敵を射程へ捉えられるか、敵の艦船・航空機の数。 |
| `landmass` | 陸塊（地上部隊が陸路で行き来できるセルのまとまり）ごとの未所有拠点・敵の数と、「取り残された部隊」（仕事の無い陸塊に居る部隊）の判定。 |
| `naval_combat` | 戦艦の1手。移動せずに撃てる敵が居れば期待損害価値の最大の敵を撃つ（積荷ごと沈められる輸送船を重く見る）。撃てなければ、敵の反撃圏（直接攻撃は移動力+1、間接射撃は現在の射程）を避けて次手番の射撃位置へ寄せる。弾薬切れ・燃料不足・大破では港へ戻る。 |
| `sealift` | 輸送船・輸送ヘリの1手。降車 → 出発・航行 → 迎え → 乗船 → 集結 の順に選ぶ。揚陸地点は積荷の目標（占領役は未所有拠点、戦闘役は敵）の近くに絞り、護衛の無い占領役は降車セルの近くの敵だけで危険を見積もる。輸送ヘリは燃料切れ（墜落）の前に空港へ戻す。 |
| `production` | 作戦生産の補正。仕事の無い陸塊で輸送能力を超えて地上部隊を買う命令を見送り、余った資金で輸送部隊・戦艦・航空機を補う。 |

手番進行での位置:

1. 戦艦の射撃・位置取り（他unitの攻撃より先に撃ち、後続の直接攻撃が撃破を取りやすくする）
2. 港・空港の明け渡し（海で隔てられた盤面か、敵が艦船を持つ盤面に限る）
3. 島嶼間輸送
4. 従来の輸送Squad・通常行動
5. 作戦生産（運べない地上部隊の購入は見送る）→ 余剰資金での補充生産

### 艦船・航空機を使う条件

- 戦艦は、自軍の港から敵を射程へ捉えられ、かつ「首都同士が海で隔てられている」か「敵が艦船を持っている」場合だけ買う。
  map_2 のように首都同士が陸続きで敵が艦船を持たない盤面では、港があっても艦船へ資金を割かない。
- 戦艦の上限は「敵戦艦の数 + 支援枠（海で隔てられていれば2、そうでなければ1）」で、余剰資金が戦艦3隻分あるごとに1隻増やす。
- 航空機は、首都同士が海で隔てられ、自軍の空港がある場合だけ補う。敵の航空戦力が地上・海上戦力の半分以上なら戦闘機（爆撃機主体なら重戦闘機）、そうでなければ爆撃機（資金不足なら戦闘ヘリ）。
- 輸送部隊は、取り残された部隊が積載枠に達したら買い足す。占領役だけなら輸送ヘリ（空港）、戦車などが溜まれば輸送船（港）。

### 島嶼作戦（V3/V4共通）の修正

- 拠点を持たず上陸部隊だけが居る島は `Threatened`（防衛）にせず、`Secured`（未所有拠点の確保）として占領を続ける。
- 自島・確保済み島の未所有施設の確保（`Secure`）を、洋上の兵站拠点より先に資金配分する。
- 輸送役の割当を、全探索から増加路法の容量付き二部マッチングへ置き換えた（結果は同じで多項式時間）。

### 生産の見送りの位置

運べない地上部隊の購入の見送り（`maritime::rejects_ground_purchase`）は、V4 の発行入口
（`issue_next_planned_production` と島嶼作戦の `take_campaign_command`）で判定する。見送った購入は
Issued へ進めず、未発行の取消と同じく配備・占領意図を解放する。手番進行（`runtime/turn.rs`）は
計画の列を読み直さない。

## 中央の島の取り残し（map_18）

### 原因

map_18 では、中央の島（拠点36）を確保し終えるまで敵本土への強襲が始まらない（兵站前提のゲート）。
この島の作戦は次の2点で途中から止まっていた。

- 占領目標を「島全体で最も前線に近い施設の一帯」だけに絞っていたため、最寄りの一帯（中央の空港群）が
  詰まると、離れた都市群へは誰も向かわなかった。
- 作戦の必要数を超えた占領役は首都強襲の輸送待ち（出発不可のForming）へ移される。この待機中の歩兵が
  未所有の拠点の上や通路に立ったまま占領せず、最後の拠点が残り続けてゲートが永久に開かなかった。

### 対応

- **施設群ごとの前線帯**（`island_campaign_analysis::property_group_fronts`、V4のみ）:
  近い施設のまとまり（3マス以内で連鎖する施設）ごとに前線帯を持つ。最寄りの施設群を先に並べて
  占領役を集中させ、それ以外の施設群は周囲3マスに敵の地上部隊が居ない場合だけ加える
  （劣勢で少数を各施設群へ分けると各個に撃破されるため）。
- **輸送待ちの占領役による足元の占領**（`v4::forming_capture`）: 輸送Squadで待機中の占領役が
  未所有の拠点の上に立っていれば、その場で占領させる。

### 評価（map_18、seed 1〜10、先後両方）

| 条件 | 変更前 | 変更後 |
| --- | --- | --- |
| 先攻 | — | 10/10 勝（全局で中央の島を取り切り、拠点44〜45対9〜10） |
| 後攻 | 9/10 勝（平均拠点31.6） | 8/10 勝（平均拠点34.7） |
