# map_20 砲撃・前進・戦車損失の検証

V4先手対V200、seed1、hex、T22まで各手番の直前・直後の盤面を保存して再現。T20の地上72体すべての位置が元の対戦と一致。

T20のV4手番終了までに戦車系を9体生産（重戦車2、中戦車3、軽戦車4）。その時点で6体を失い、地上記録に残るのは3体。敵T20の攻撃でさらに中戦車1体を失う。単に生産数が3体だったわけではない。

T1–22に砲兵が最後の攻撃者として敵を除去した事例は16件。その撃破セルに同一手番中に既存の戦車が前進した事例を2件確認。機会が同等とは限らないため、2/16を連携の成功率とは扱わない。

- T14: 砲台が(8,18)の敵ロケットランチャーを撃破。軽戦車4294967409が同セルへ移動。T15の自軍攻撃に対する反撃で消失。
- T15: 砲台が(18,6)の敵軽歩兵を撃破。軽戦車8589934677が同セルへ移動。T16の敵手番に重自走砲・歩兵の攻撃を受け消失。

T20の自軍手番までの戦車損失6体のうち4体は、敵の重自走砲が参加する攻撃を受けた手番で消失。残り2体は自軍攻撃の反撃で消失。

砲撃→戦車前進の行動は存在するが、前進地点を維持できず戦車が減る。必要な生産数、補充判断、敵間接火力を残した進入の妥当性は別途検証が必要。
