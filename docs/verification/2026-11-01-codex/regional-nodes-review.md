# 地域ノード改修の検証

ノード構築を、施設の最寄り経路セルの列挙から、地域代表点を先に選び施設を地域へ所属させる構造へ変更した。首都地域を優先し、通常ノードには周囲のAreaを持たせ、橋の通過Pointを維持した。地域内の施設は単一の作戦だけに所属する。

地域Captureの局地優勢を前衛の出口条件に反映し、前線目標の探索にも接続した。未占領施設の予約と占領任務はSecuredまで維持する。

## 検証

- map_20 両陣営の構造テスト：首都隣接工場は首都地域に所属し、独立した工場ノードを作らない。目標の所属重複なし。
- engine: 1148 passed / 0 failed / 1 ignored。
- cargo clippy --offline --all-targets --all-features -- -D warnings 成功。
- fmt / diff check 成功。
- 実対戦：seed=1, hex, V4対V200。map_20は両手番45ターン、map_47は先手のみ。

## 結果と残課題

map_20では行動・経路目標が変化した。先手40ターンで主目標は(24,13)地域へ進んだが、同地域がContestedで首都地域はLocked、首都地域への担当割当は45ターンまで出ていない。後手でも首都地域はLocked。従って、首都進軍と生産封鎖の並行実行という狙いは未達。

42ターンの所有拠点数は先手23→26、後手21→20。後手で減少があり、副作用なしとは評価できない。

map_47先手は36ターンで終了（前回46ターン）。ただし敵首都の所有者は敵のままで、首都ノードもLocked。この対戦結果を首都進軍改善の証拠とはしない。

地域内部の施設依存は除けたが、地域間の依存と実行部隊の配分には課題が残る。地域構造の修正と全体の狙い達成を区別し、完成扱いにしない。
