# DATABASE.md - データ保存設計書

> ※ 本プロジェクトはローカルゲームアプリであり、本格的なRDBMS（PostgreSQL, MySQL等）は使用しません。主にファイルベースの永続化を対象とします。

## 1. 概要

### データストア構成
- **フォーマット**: JSON, CSV
- **用途**: 
  - マスターデータ（ユニットステータス、地形効果など）
  - セーブデータ（ゲームの進行状況、現在のマップ状態）

## 2. セーブデータ仕様

### 構造
ゲームの状態は、ECSのエンティティとコンポーネントをシリアライズしてJSON形式等で保存します。

- 勢力情報（所持金、同盟状況、現在のターンなど）
- 配置されている全ユニットの状態（ID、座標、HP、残り行動力、所属）
- マップの各セルの占領状態（どの拠点がどの勢力のものか）

## 3. マスターデータ仕様

### 構造
ユニットの種類ごとの基本パラメータ等はCSV（またはJSON）で管理し、ゲーム起動時に `Resource` としてメモリにロードします。

- ユニット種別マスター (UnitType, 最大HP, 移動力, 基礎攻撃力...)
- 地形マスター (TerrainType, 防御ボーナス, 移動コスト...)

## 4. トランザクション・安全な保存
ローカルへのファイル書き込みとなるため、書き込み中のクラッシュや強制終了によるデータ破損を防ぐため、一時ファイルへ書き込んでからリネームするなどのアトミックなファイルI/Oを実施する想定です。
