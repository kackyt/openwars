## MODIFIED Requirements

### Requirement: 輸送ユニット被弾時の搭載ユニット HP 同期

MUST: エンジンは、輸送ユニットが新たにHPダメージを受けた場合にのみ、正しく搭載されたユニットのHPを輸送ユニットの現在HP以下へ引き下げなければならない。輸送ユニットが撃破された場合、搭載ユニットも撃破状態にしなければならない。

#### Scenario: 輸送ユニット被弾による HP 同期
- **WHEN** 輸送ユニットが攻撃を受けてHPが減少する
- **THEN** 搭載ユニット全員のHPは輸送ユニットの現在HP以下になる

#### Scenario: 平時の搭載HP維持
- **GIVEN** 損傷した輸送ユニットより高いHPを持つ搭載ユニットがいる
- **AND** 輸送ユニットは新たなダメージを受けていない
- **WHEN** エンジンの次フレームを実行する
- **THEN** 搭載ユニットのHPは引き下げられない
