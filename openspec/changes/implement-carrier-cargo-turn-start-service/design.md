## Context

空母と搭載ユニットの関係は親の `CargoCapacity.loaded` と子の `Transporting` で表します。親の搭載順を資金配分の順序として利用し、子の逆参照も検証します。

## Decisions

- 空母は `UnitType::Carrier`、自軍所属、生存、非搭載の条件を満たすときだけサービスします。
- 修理上限は20内部HPです。費用は `unit_cost * repaired_hp / 100` の床関数とし、残資金以下になる最大の修理量を選びます。
- 複数の空母は Entity ID 順、同一空母内では `loaded` 順に処理します。
- 燃料・弾薬はHP修理費の有無に関係なく無償で回復します。
- 搭載中の航空機は格納中であるため、日次燃料消費と墜落判定を受けません。
- 搭載ユニットHPは、輸送ユニットに新しい被弾が発生した場合のみ下げます。これにより空母サービス後のHPを平時に巻き戻しません。イベントなしのHP0輸送ユニットは撃破伝播のため同期対象に残します。

## Non-goals

既存の拠点補給価格・資金不足時挙動、手動補給コマンド、UI、セーブ形式、マスターデータは変更しません。
